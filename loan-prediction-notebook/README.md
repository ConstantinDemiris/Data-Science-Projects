# Loan Prediction Jupyter Notebook Assignment

This project contains a fully commented Jupyter Notebook based on the provided `loanP_train.csv` dataset.

## Files

- `Loan_Prediction_Commented.ipynb` — commented and executable notebook.
- `loanP_train.csv` — original dataset provided with the assignment.
- `loanP_train_cleaned.csv` — cleaned dataset generated by the notebook.

## Notebook sections

1. Import libraries.
2. Load and inspect the dataset.
3. Remove duplicate rows.
4. Fill missing categorical and numeric values.
5. Prepare features and the loan-status target.
6. One-hot encode categorical predictors.
7. Create training and testing sets.
8. Standardize continuous numeric features.
9. Train a logistic regression model.
10. Evaluate model performance.
11. Save the cleaned dataset.

Open the notebook in Jupyter Notebook or JupyterLab and select **Run All**. The notebook expects the CSV file to be in the same folder.
