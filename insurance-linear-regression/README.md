# Insurance Linear Regression

This project performs multiple linear regression on `insuranceData.csv` using Python and scikit-learn.

## Assignment requirements completed

- Imported NumPy, pandas, Matplotlib, Seaborn, and relevant scikit-learn tools.
- Loaded `insuranceData.csv`.
- Applied `LabelEncoder()` to the categorical `smoker` field.
- Applied the current `OneHotEncoder()` and `ColumnTransformer` method.
- Reserved 15% of the records for testing.
- Trained and evaluated a multiple linear regression model.
- Added comments and explanations throughout the notebook.

## Files

- `Insurance_Linear_Regression.ipynb` — fully commented Jupyter Notebook.
- `insuranceData.csv` — medical insurance dataset used by the notebook.

Open the notebook in Jupyter Notebook or JupyterLab and select **Run All**.
